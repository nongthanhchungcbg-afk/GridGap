# CSS Grid: `grid-gap`

Hai ví dụ minh họa thuộc tính viết tắt `grid-gap`:

- `grid-gap: 20px` đặt khoảng cách hàng và cột bằng nhau.
- `grid-gap: 30px 10px` đặt row-gap 30px, column-gap 10px.

## Chạy và chụp ảnh

Mở `index.html` trong trình duyệt. Cả hai ví dụ, chú thích và CSS mẫu hiển thị cùng trang; chụp màn hình trang để nộp.

Trong CSS hiện đại có thể dùng `gap` thay cho `grid-gap`.
